# 年龄录入产品规划

- 摘要：「年龄录入」是面向 PC 端的轻量应用，不启用认证与权限控制。应用只有一个页面，页面上显示当前时间，没有任何后端 API 和实体。导航采用侧边布局，页头启用、页脚禁用。业务参与者为普通使用者，打开应用即可查看当前时间。
- 状态：confirmed
- 版本：0.1.0

## 页面与用户操作

### 首页

- 页面 ID：`home_page`
- 路由：`/page/home`
- 页面目标：让普通使用者打开应用后，在唯一首页直接看到当前时间。
- 页面跳转：无

业务信息：
- `home_page_current_time` 当前时间：页面展示的当前时间，供普通使用者直接查看。

核心操作：
- 无

产品验收标准：
- 普通使用者打开应用后进入首页，页面展示当前时间。
- 首页不要求登录，也不展示任何权限受限内容。
- 首页不涉及任何业务数据的录入、查询或修改。

## 产品级验收标准

- 普通使用者无需登录即可打开「年龄录入」应用并进入首页。
- 首页展示当前时间，且不依赖任何后端 API 或实体数据。
- 应用只有一个页面，导航采用侧边布局，页头启用、页脚禁用。
- 应用不启用认证与权限控制，普通使用者可访问全部页面内容。
