### 1. axios 依赖声明版本低于安全基线

- 严重级别：中风险
- 规则 ID：`unknown`
- 范围：前端
- 文件位置：`frontend/package.json:23`
- 说明：dependencies 中 axios 声明为 ^1.3.6，其下界 1.3.6 位于风险区间 [1.0.0, 1.15.0)。锁文件当前解析到 1.20.0，符合 >=1.15.0 的安全范围，但该声明范围仍允许安装到不受支持的旧版本，建议将声明版本提升到 1.15.0 及以上。

### 2. 间接依赖 form-data 版本低于安全基线

- 严重级别：高风险
- 规则 ID：`unknown`
- 范围：前端
- 文件位置：`frontend/pnpm-lock.yaml:1767`
- 说明：锁文件中存在 form-data@2.3.2，低于安全范围下界 2.5.4，属于风险版本；同一文件另有 form-data@4.0.6 符合 >=4.0.4 的安全范围。需通过 pnpm overrides 将 form-data 统一提升到 4.0.5 并重新安装以更新锁文件。

### 3. CORS 允许任意来源且允许携带凭据

- 严重级别：高风险
- 规则 ID：`unknown`
- 范围：后端
- 文件位置：`backend/src/main/java/com/cmbchina/backend/common/config/CrosConfig.java:12`
- 说明：全局 CORS 配置使用通配来源模式并同时开启凭据携带，任意站点均可在携带 Cookie 的情况下调用后端接口，存在跨站请求伪造与数据泄露风险。应改为明确的来源白名单，或在不携带凭据时再放开来源。

### 4. 统一异常处理器未覆盖数据库异常

- 严重级别：低风险
- 规则 ID：`CKR7019`
- 范围：后端
- 文件位置：`backend/src/main/java/com/cmbchina/backend/common/exception/BaseExceptionHandler.java:14`
- 说明：统一异常处理器仅显式处理业务异常与参数校验异常，未针对数据库访问异常设置项目约定的非成功返回码与通用错误文案；数据库异常会走默认错误处理路径，可能向调用方暴露 SQL 细节。建议在统一处理器中补充数据库异常分支并返回通用提示。
