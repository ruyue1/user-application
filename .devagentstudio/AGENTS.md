## 分支 v1_0（2026-11-13 02:12:15 UTC）

**变更说明**：Z000000-0000 #comment chore: 新增欢迎页面，页面会向用户展示固定的"hello world"欢迎语，并配置了对应的访问入口。

### 应用现状

- 应用名称：欢迎页
- 应用场景：我要开发一个简单的纯展示的hello world页面，只展示写死的字符串“hello world”，不需要任何后端api接口
- 目标终端：PC
- 导航布局：布局=side, 页头=启用, 页脚=禁用
- 主题色：#6b3cf0
- 数据源类型：database
- 认证：不启用
- 权限控制：不启用

### 需求规格

> 一个简单的纯展示应用，在欢迎页上展示固定的"hello world"字符串，无需后端API接口。适用于PC端，采用侧边导航布局，启用页头、禁用页脚。

**用户角色**：
- 访客：访问欢迎页查看hello world展示内容的用户

**功能模块**：
- 展示模块（must）：负责在欢迎页展示固定的hello world字符串内容

### 产品计划

**页面**：
- **欢迎页**（home，路径：/page/home）
  - 描述：展示固定字符串"hello world"的欢迎页面
  - 目标：向用户展示固定的'hello world'字符串内容

**业务流程**：
- 查看Hello World
  - 用户打开应用，在欢迎页查看展示的hello world字符串
  - 步骤：用户打开应用进入欢迎页
  - 步骤：页面展示固定的hello world字符串

### UI 设计稿

- home

### 技术计划

- 前端架构：基于单页应用生成页面、路由和 API 客户端。
- 后端架构：后端技术栈固定为 Java8 + Springboot，提供真实 HTTP API、资源接口和业务契约实现。
- 数据层：数据库固定使用 MySQL8，缓存固定使用 Redis。

## 分支 v1_1（2026-11-13 03:23:45 UTC）

**变更说明**：Z000000-0000 #comment chore: 新增展示固定欢迎语的欢迎页，以及通过后端接口获取并展示问候语的问候页。

### 应用现状

- 应用名称：欢迎页
- 应用场景：我要开发一个简单的纯展示的hello world页面，只展示写死的字符串“hello world”，不需要任何后端api接口
- 目标终端：PC
- 导航布局：布局=side, 页头=启用, 页脚=禁用
- 主题色：#6b3cf0
- 数据源类型：database
- 认证：不启用
- 权限控制：不启用

### 需求规格

> 一个简单的展示应用，包含欢迎页展示固定的"hello world"字符串，以及问候页通过后端接口/api/hi获取并展示"欢迎来到我的世界！"字符串。适用于PC端，采用侧边导航布局，启用页头、禁用页脚。

**用户角色**：
- 访客：访问应用查看展示内容的用户

**功能模块**：
- 展示模块（must）：负责在欢迎页展示固定的hello world字符串内容
- 问候展示模块（must）：通过后端接口/api/hi获取并展示问候语内容

### 产品计划

**页面**：
- **欢迎页**（home，路径：/page/home）
  - 描述：展示固定字符串"hello world"的欢迎页面
  - 目标：向用户展示固定的'hello world'字符串内容
- **问候页**（greeting，路径：/page/greeting）
  - 描述：调用后端接口/api/hi获取并展示"欢迎来到我的世界！"字符串的页面
  - 目标：向用户展示通过后端接口/api/hi获取的问候语内容"欢迎来到我的世界！"

**业务流程**：
- 查看Hello World
  - 用户打开应用，在欢迎页查看展示的hello world字符串
  - 步骤：用户打开应用进入欢迎页
  - 步骤：页面展示固定的hello world字符串
- 查看问候语
  - 用户打开问候页，页面通过后端接口/api/hi获取并展示问候语内容
  - 步骤：用户打开应用进入问候页
  - 步骤：页面调用后端接口/api/hi获取问候语
  - 步骤：页面展示"欢迎来到我的世界！"字符串

### UI 设计稿

- home
- greeting

### 技术计划

- 前端架构：基于单页应用生成页面、路由和 API 客户端。
- 后端架构：后端技术栈固定为 Java8 + Springboot，提供真实 HTTP API、资源接口和业务契约实现。
- 数据层：数据库固定使用 MySQL8，缓存固定使用 Redis。

**实体**：
- **问候语**（greeting）
  - 描述：通过后端接口获取并展示的问候语内容
  - 问候语内容（content）：text，必填

### 接口设计

- **endpoint--greeting--greeting-getGreeting**
