### 需求规格

> 一个仅面向 PC 端的纯展示型 Hello World 应用，核心页面固定展示字符串 “hello world”，不含任何后端 API 接口与业务操作；采用侧边导航布局，启用页头、禁用页脚；不启用认证与权限控制。

**用户角色**：
- 访问者：浏览纯展示页面的使用者，仅查看页面上写死的 “hello world” 字符串，无任何业务操作权限。

**功能模块**：
- Hello World 展示管理（must）：负责应用唯一展示能力：在页面固定位置展示写死的字符串 “hello world”。该字符串为静态内容，不依赖任何后端 API 接口或数据交互；不做唯一性校验、不提供编辑、删除或搜索等操作；整体布局采用侧边导航，启用页头、禁用页脚，目标终端为 PC。

### 产品计划

**页面**：
- **Hello World 展示页**（hello_world_display，路径：/page/hello-world-display）
  - 描述：应用首页，纯静态展示页面。页面固定展示字符串 “hello world”，无任何输入、按钮、表单或数据请求；作为侧边导航布局下的默认内容区，顶部显示页头，底部不显示页脚。
  - 目标：作为应用默认落地内容区，让访问者在进入应用后立即看到固定的 “hello world” 字符串，确认应用可正常访问，不提供任何交互或业务操作。

**业务流程**：
- 查看 Hello World 展示页
  - 访问者打开应用首页并直接看到固定的 “hello world” 字符串，全程无需登录、无需交互、不触发任何后端请求。
  - 步骤：访问者在 PC 端打开应用，进入首页 Hello World 展示页。
  - 步骤：页面直接渲染写死的字符串 “hello world”。
  - 步骤：访问者浏览页面内容，流程结束，无需任何后续操作。
