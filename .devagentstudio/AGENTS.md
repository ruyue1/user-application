**变更说明**：Z000000-0000 #comment chore: 新增晚间问候页与欢迎世界页，并完成后端问候语服务能力建设，实现页面动态获取并展示“晚上好！”及“欢迎来到我的世界！”问候内容。

### 应用现状

- 应用名称：测试
- 应用场景：1、实现一个前端页面，页面上一个接口返回字符串“晚上好！”，前端展示这个字符串
2、再实现一个前端页面，页面上一个接口返回字符串“欢迎来到我的世界！”，前端展示这个字符串
- 目标终端：PC
- 导航布局：布局=side, 页头=启用, 页脚=禁用
- 主题色：#6b3cf0
- 数据源类型：database
- 认证：不启用
- 权限控制：不启用

### 需求规格

> 一个面向PC端的基础展示应用，包含两个前端页面：第一个页面通过接口获取并展示字符串“晚上好！”，第二个页面通过接口获取并展示字符串“欢迎来到我的世界！”。

**用户角色**：
- 访问用户：通过浏览器访问前端页面并查看接口返回文本的用户。

**功能模块**：
- 问候语展示模块（must）：负责请求接口并在前端页面展示固定问候文本内容。

### 产品计划

**页面**：
- **晚间问候页**（good_evening，路径：/page/good-evening）
  - 描述：调用接口获取字符串“晚上好！”并在前端页面进行展示。
  - 目标：向访问用户清晰、直接地呈现晚间问候语“晚上好！”。
- **欢迎世界页**（welcome_world，路径：/page/welcome-world）
  - 描述：调用接口获取字符串“欢迎来到我的世界！”并在前端页面进行展示。
  - 目标：向访问用户清晰、直接地呈现欢迎语“欢迎来到我的世界！”。

**业务流程**：
- 查看晚间问候语流程
  - 访问用户打开晚间问候页并查看接口返回的“晚上好！”文本。
  - 步骤：访问用户进入晚间问候页
  - 步骤：前端页面请求对应接口获取返回字符串“晚上好！”
  - 步骤：前端页面将字符串“晚上好！”展示给用户
- 查看欢迎世界问候语流程
  - 访问用户打开欢迎世界页并查看接口返回的“欢迎来到我的世界！”文本。
  - 步骤：访问用户通过侧边导航切换进入欢迎世界页
  - 步骤：前端页面请求对应接口获取返回字符串“欢迎来到我的世界！”
  - 步骤：前端页面将字符串“欢迎来到我的世界！”展示给用户

### UI 设计稿

- good_evening
- welcome_world

### 技术计划

- 前端架构：基于单页应用生成页面、路由和 API 客户端。
- 后端架构：后端技术栈固定为 Java8 + Springboot，提供真实 HTTP API、资源接口和业务契约实现。
- 数据层：数据库固定使用 MySQL8，缓存固定使用 Redis。

**实体**：
- **问候语**（greeting_message）
  - 描述：用于承载前端页面请求并展示的问候字符串内容，如“晚上好！”与“欢迎来到我的世界！”。
  - 场景标识（scene_code）：text，必填
  - 问候语内容（greeting_text）：text，必填

### 接口设计

- **获取晚间问候语**
  - GET /api/greetings/good-evening
  - 契约 `greeting_message_contract`，端点 `greeting_message_contract.get_good_evening`
  - 描述：获取晚间问候页所需的问候语内容“晚上好！”，供前端页面直接展示。
- **获取欢迎世界问候语**
  - GET /api/greetings/welcome-world
  - 契约 `greeting_message_contract`，端点 `greeting_message_contract.get_welcome_world`
  - 描述：获取欢迎世界页所需的问候语内容“欢迎来到我的世界！”，供前端页面直接展示。
