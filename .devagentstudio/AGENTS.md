## 分支 v1_0（2026-11-10 06:07:27 UTC）

**变更说明**：新增Hello World展示页，页面会展示固定的“hello world”文字内容。

### 应用现状

- 应用名称：欢迎页
- 应用场景：我要开发一个简单的纯展示的hello world页面，只展示写死的字符串“hello world”，不需要任何后端api接口
- 目标终端：PC
- 导航布局：布局=side, 页头=启用, 页脚=禁用
- 主题色：#6b3cf0
- 数据源类型：database
- 认证：不启用
- 权限控制：不启用

### 需求规格

> 一个简单的纯展示应用，在PC端展示写死的字符串'hello world'，采用侧边导航布局，启用页头，禁用页脚，无需后端API接口。

**用户角色**：
- 访客：访问并查看hello world展示页面的用户

**功能模块**：
- 展示模块（must）：负责展示hello world内容的模块

### 产品计划

**页面**：
- **Hello World展示页**（hello_world，路径：/page/hello-world）
  - 描述：展示写死的字符串'hello world'的页面
  - 目标：向用户展示固定的'hello world'文本内容

**业务流程**：
- 查看Hello World
  - 用户访问应用并查看hello world展示内容
  - 步骤：用户打开应用进入展示页

### UI 设计稿

- 前端架构：基于单页应用生成页面、路由和 API 客户端。
- 后端架构：后端技术栈固定为 Java8 + Springboot，提供真实 HTTP API、资源接口和业务契约实现。
- 数据层：数据库固定使用 MySQL8，缓存固定使用 Redis。
