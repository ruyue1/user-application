**变更说明**：Z000000-0000 #comment chore: 新增欢迎页问候语功能，完成前后端数据联调。用户进入应用主页面时，将自动从服务端获取并在页面上展示“早上好！”问候信息。

### 应用现状

- 应用名称：欢迎页
- 应用场景：开发一个前端页面，页面上一个接口返回字符串“早上好！”，前端展示这个字符串
- 目标终端：PC
- 导航布局：布局=side, 页头=启用, 页脚=禁用
- 主题色：#6b3cf0
- 数据源类型：database
- 认证：不启用
- 权限控制：不启用

### 需求规格

> 一个面向 PC 端的欢迎页应用，前端页面调用后端接口获取字符串“早上好！”并进行展示。

**用户角色**：
- 访客用户：访问欢迎页并查看页面展示的问候字符串“早上好！”的用户。

**功能模块**：
- 问候语展示（must）：调用接口获取问候字符串“早上好！”并在前端页面进行展示。

### 产品计划

**页面**：
- **欢迎页**（home，路径：/page/home）
  - 描述：应用主页面，进入页面时请求接口获取字符串“早上好！”并在前端页面展示。
  - 目标：向访问应用的用户清晰展示问候语“早上好！”。

**业务流程**：
- 查看问候语流程
  - 用户访问欢迎页，前端请求接口并展示返回的字符串“早上好！”。
  - 步骤：用户打开 PC 端欢迎页
  - 步骤：前端页面调用问候语接口获取返回的字符串“早上好！”
  - 步骤：前端页面在界面上展示字符串“早上好！”

### UI 设计稿

- home

### 技术计划

- 前端架构：基于单页应用生成页面、路由和 API 客户端。
- 后端架构：后端技术栈固定为 Java8 + Springboot，提供真实 HTTP API、资源接口和业务契约实现。
- 数据层：数据库固定使用 MySQL8，缓存固定使用 Redis。

**实体**：
- **问候语**（greeting）
  - 描述：用于承载欢迎页展示的问候字符串“早上好！”
  - 问候语文本（morning_greeting_text）：text，必填

### 接口设计

- **获取问候语**
  - GET /api/greetings/morning
  - 契约 `greeting_contract`，端点 `greeting_contract.get_morning_greeting`
  - 描述：获取欢迎页展示的问候字符串“早上好！”
