### 需求规格

> 一个简单的纯展示型 PC 应用，仅包含一个静态展示页面，页面上直接展示写死的字符串“hello world”。应用不使用任何后端 API 接口，认证未启用，也没有权限控制要求。采用带页头的侧边导航布局，页脚禁用。

**用户角色**：
- 访问者：访问并查看纯展示页面内容的用户。

**功能模块**：
- Hello World 展示（must）：提供纯展示性质的页面内容管理能力。该模块承载一个静态页面，页面内容为固定写死的字符串“hello world”，不涉及任何数据交互、编辑或提交操作，也不依赖后端 API 接口。

### 产品计划

**页面**：
- **Hello World 展示**（hello_world_display，路径：/page/hello-world-display）
  - 描述：应用首页，纯展示页面。页面中直接展示写死的字符串“hello world”，不可编辑、无输入控件、无任何数据请求；采用带页头的侧边导航布局，页脚禁用。
  - 目标：让访问者在无需登录、无需任何操作的条件下，直接看到固定内容“hello world”，确认应用可正常访问。

**业务流程**：
- 查看 Hello World 内容
  - 访问者打开应用首页即可查看静态展示的“hello world”字符串，无需登录，无需任何数据交互。
  - 步骤：访问者打开应用首页。
  - 步骤：页面通过侧边导航布局加载，展示页头并隐藏页脚。
  - 步骤：页面直接显示写死的字符串“hello world”，流程结束。
