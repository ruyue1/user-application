## 分支 v1_2（2026-11-12 12:26:29 UTC）

**变更说明**：Z000000-0000 #comment chore: 111

### 应用现状

- 应用名称：欢迎页
- 应用场景：我要开发一个简单的纯展示的hello world页面，只展示写死的字符串“hello world”，不需要任何后端api接口
- 目标终端：PC
- 导航布局：布局=side, 页头=启用, 页脚=禁用
- 主题色：#6b3cf0
- 数据源类型：database
- 认证：不启用
- 权限控制：不启用

### 需求规格

> 一个纯展示应用，包含两个页面：首页展示写死的字符串 hello world；另一个页面先展示写死的字符串"你好"，再调用后端接口 /api/hi 获取并展示系统时间。面向 PC 端，采用侧边导航布局，启用页头、禁用页脚。

**用户角色**：
- 访客：访问页面的用户，无需登录即可查看内容

**功能模块**：
- 展示模块（must）：展示写死的 hello world 字符串的页面模块
- 时间展示模块（must）：展示写死的"你好"字符串并调用后端接口 /api/hi 获取系统时间展示在下方的页面模块

### 产品计划

**页面**：
- **Hello World 展示页**（hello_world，路径：/page/hello-world）
  - 描述：展示写死的字符串 hello world，纯前端展示，无后端接口调用
  - 目标：让用户在打开应用首页时立即看到写死的 hello world 字符串，完成纯展示目的，无需任何交互或数据请求。
- **你好时间展示页**（hi_time，路径：/page/hi）
  - 描述：页面先展示写死的字符串"你好"，下方再展示通过后端接口 /api/hi 获取的系统时间
  - 目标：向访客展示写死的问候字符串"你好"，并在其下方展示通过后端接口 /api/hi 获取的系统时间

**业务流程**：
- 查看 Hello World
  - 用户打开应用首页，页面展示写死的字符串 hello world
  - 步骤：用户打开应用首页
  - 步骤：页面展示写死的字符串 hello world
- 查看你好时间
  - 用户打开你好时间展示页，页面先展示写死的字符串"你好"，再调用后端接口 /api/hi 获取系统时间并展示在下方
  - 步骤：用户打开你好时间展示页
  - 步骤：页面展示写死的字符串"你好"
  - 步骤：页面调用后端接口 /api/hi 获取系统时间
  - 步骤：页面在"你好"下方展示返回的系统时间

### UI 设计稿

- hello_world
- hi_time

### 技术计划

- 前端架构：基于单页应用生成页面、路由和 API 客户端。
- 后端架构：后端技术栈固定为 Java8 + Springboot，提供真实 HTTP API、资源接口和业务契约实现。
- 数据层：数据库固定使用 MySQL8，缓存固定使用 Redis。

**实体**：
- **系统时间**（system_time）
  - 描述：后端系统当前时间，通过接口获取用于页面展示
  - 当前时间（current_time）：datetime，必填

### 接口设计

- **endpoint--system_time--system_time-get_time**
