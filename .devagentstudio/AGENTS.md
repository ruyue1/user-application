### 需求规格

> 一个仅用于展示的简单 Hello World 页面应用，面向 PC 端。页面中只展示写死的字符串「hello world」，不调用任何后端 API 接口。应用采用侧边导航布局，启用页头、禁用页脚，不启用认证，也不做任何权限控制。

**用户角色**：
- 访客：打开并浏览 Hello World 展示页面，查看页面中写死的「hello world」字符串内容。

**功能模块**：
- Hello World 展示（must）：负责在页面上展示写死的字符串「hello world」。该模块不涉及任何后端 API 接口调用，也不涉及数据的增删改查操作，仅提供静态内容展示；页面采用侧边导航布局，启用页头、禁用页脚。

### 产品计划

**页面**：
- **Hello World 展示页**（hello_world_display，路径：/page/hello-world-display）
  - 描述：应用首页，用于展示写死的字符串「hello world」。页面采用侧边导航布局，包含页头，不包含页脚；不调用任何后端接口，不提供任何数据操作，供访客直接浏览。
  - 目标：让访客打开应用后即可直接看到固定的「hello world」字符串，无需登录、无需任何数据交互即可完成浏览。

**业务流程**：
- 浏览 Hello World 展示内容
  - 访客打开应用后，直接查看页面中写死的「hello world」字符串。整个流程不涉及认证、权限校验或后端数据交互。
  - 步骤：访客访问应用首页 /，进入 Hello World 展示页。
  - 步骤：页面通过侧边导航布局与页头呈现，不显示页脚。
  - 步骤：页面展示写死的字符串「hello world」。
  - 步骤：访客浏览完成后可直接离开，系统不做任何记录或后续处理。
