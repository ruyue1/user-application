### 需求规格

> 「简单测试」是一个面向 PC 终端的单页面应用，页面加载后向后端服务器请求并展示当前服务器时间，用于验证前后端连通性。应用采用侧边导航（side）布局，启用页头、禁用页脚，不启用认证，也不涉及权限控制。

**用户角色**：
- 普通用户：打开应用页面查看后端服务器时间的终端使用者。

**功能模块**：
- 服务器时间展示（must）：页面加载时从后端服务器获取当前服务器时间，并在页面上展示该时间结果。

### 产品计划

**页面**：
- **服务器时间展示页**（home，路径：/page/home）
  - 描述：应用唯一页面，进入后自动请求后端服务器时间，并在页面中直接展示返回的服务器时间。
  - 目标：让用户打开应用后即可看到后端服务器返回的当前时间，以确认前后端连通性。

**业务流程**：
- 查看后端服务器时间
  - 用户打开应用首页后，页面请求后端服务器时间并展示当前时间结果。
  - 步骤：用户打开应用首页。
  - 步骤：页面向后端服务器发起当前时间查询请求。
  - 步骤：后端服务器返回当前服务器时间。
  - 步骤：页面展示后端返回的服务器时间。

### 技术计划

- 前端架构：基于单页应用生成页面、路由和 API 客户端。
- 后端架构：后端技术栈固定为 Java8 + Springboot，提供真实 HTTP API、资源接口和业务契约实现。
- 数据层：数据库固定使用 MySQL8，缓存固定使用 Redis。

**实体**：
- **服务器时间**（server_time）
  - 描述：后端服务器返回的当前时间，用于页面展示并确认前后端连通性。
  - 当前时间（current_time）：datetime，必填

### 接口设计

- **读取服务器时间**
  - GET /api/server-time
  - 契约 `server_time_contract`，端点 `server_time_contract.read_server_time`
  - 描述：返回后端服务器当前时间，供页面展示并确认前后端连通性。
