# 欢迎页需求 Spec

## 应用信息

- 名称：欢迎页
- 目标：
- 确认需求摘要：一个简单的展示应用，包含欢迎页展示固定的"hello world"字符串，以及问候页通过后端接口/api/hi获取并展示"欢迎来到我的世界！"字符串。适用于PC端，采用侧边导航布局，启用页头、禁用页脚。
- 状态：已确认
- 版本：1.0.0

## 业务参与者（非授权角色）

- `visitor` 访客：访问应用查看展示内容的用户

## 权限需求

- 不涉及应用级资源授权。

## 认证需求

- 不涉及登录认证基础能力。

## 功能模块

- `display` 展示模块：负责在欢迎页展示固定的hello world字符串内容（must）
- `greeting` 问候展示模块：通过后端接口/api/hi获取并展示问候语内容（must）

## 页面清单

- `/page/home` 欢迎页：展示固定字符串"hello world"的欢迎页面
- `/page/greeting` 问候页：调用后端接口/api/hi获取并展示"欢迎来到我的世界！"字符串的页面

## 实体清单

- 暂无实体

## 业务流程

- 查看Hello World：用户打开应用，在欢迎页查看展示的hello world字符串；用户打开应用进入欢迎页 → 页面展示固定的hello world字符串
- 查看问候语：用户打开问候页，页面通过后端接口/api/hi获取并展示问候语内容；用户打开应用进入问候页 → 页面调用后端接口/api/hi获取问候语 → 页面展示"欢迎来到我的世界！"字符串
