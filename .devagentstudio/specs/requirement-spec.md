# yst登录需求 Spec

## 应用信息

- 名称：yst登录
- 目标：
- 确认需求摘要：「yst登录」是面向 PC 终端的单页面应用，启用登录认证，不涉及权限控制。用户登录后进入唯一页面，页面仅显示当前时间，不提供任何后端 API 与业务实体操作。页面采用侧边导航布局，页头启用、页脚禁用。
- 状态：已确认
- 版本：1.0

## 业务参与者（非授权角色）

- `ordinary_user` 普通用户：登录后可查看页面上显示的当前时间，无其他业务操作。

## 权限需求

- 不涉及应用级资源授权。

## 认证需求

- 不涉及登录认证基础能力。

## 功能模块

- `current_time_display` 当前时间展示：应用唯一的业务能力：在唯一页面中展示当前时间。仅提供时间信息的展示，不涉及后端数据读写、业务实体维护或其他操作。用户需先完成登录才能访问该页面；本模块不做任何权限区分，所有登录用户看到的展示内容一致。（must）

## 页面清单

- `/page/current-time-display` 当前时间展示页：应用唯一的页面，也是首页。页面采用侧边导航布局，页头启用、页脚禁用。用户登录后进入该页面，页面展示当前的日期与时间信息，供用户查看；页面上不提供任何业务操作、表单或数据维护入口。

## 实体清单

- 暂无实体

## 业务流程

- 查看当前时间：普通用户登录应用后，在唯一页面查看当前时间的流程。该流程不涉及数据提交或业务处理。；普通用户打开「yst登录」应用。 → 用户完成登录认证。 → 系统进入唯一的当前时间展示页（首页）。 → 页面展示当前日期与时间信息，用户查看该信息。
