# 年龄录入需求 Spec

## 应用信息

- 名称：年龄录入
- 目标：PC
- 确认需求摘要：「年龄录入」是面向 PC 端的轻量应用，不启用认证与权限控制。应用只有一个页面，页面上显示当前时间，没有任何后端 API 和实体。导航采用侧边布局，页头启用、页脚禁用。业务参与者为普通使用者，打开应用即可查看当前时间。
- 状态：已确认
- 版本：0.1.0

## 业务参与者（非授权角色）

- `role_ordinary_user` 普通使用者：使用该应用查看页面当前时间的一般使用者，无需登录即可访问。

## 权限需求

- 不涉及应用级资源授权。

## 认证需求

- 不涉及登录认证基础能力。

## 功能模块

- `module_age_entry` 年龄录入：应用唯一的功能模块，提供包含当前时间展示的单一页面，不涉及后端 API 与实体。（must）

## 页面清单

- `/page/home` 首页：应用唯一页面，页面显示当前时间；无后端 API、无实体数据的读写。

## 实体清单

- 暂无实体

## 业务流程

- 查看当前时间：普通使用者打开应用后，在唯一首页查看页面展示的当前时间，流程不涉及登录、权限校验或业务数据读写。；打开「年龄录入」应用 → 进入应用首页 → 在首页查看页面展示的当前时间
