# 欢迎页需求 Spec

## 应用信息

- 名称：欢迎页
- 目标：
- 确认需求摘要：一个面向 PC 终端的展示型应用，采用侧边导航布局（导航布局=side），页头启用、页脚禁用。应用共包含三个展示页面：欢迎页展示写死的“hello world”，hello agent 页面展示写死的“hello agent!”，本轮新增的早上好页面通过一个后端 API 接口获取并展示字符串“早上好!”。不启用登录认证，也不涉及权限控制。
- 状态：已确认
- 版本：1.1

## 业务参与者（非授权角色）

- `visitor` 访客：访问并浏览各展示页面的终端用户，无需登录即可查看页面内容

## 权限需求

- 不涉及应用级资源授权。

## 认证需求

- 不涉及登录认证基础能力。

## 功能模块

- `welcome_display` 欢迎页展示：提供应用的欢迎页展示能力，页面主体以静态写死的文本形式展示“hello world”，不依赖任何后端接口（must）
- `hello_agent_display` hello agent 展示：提供 hello agent 纯展示页面能力，页面主体以静态写死的文本形式展示“hello agent!”，不依赖任何后端接口（must）
- `morning_greeting_display` 早上好展示：提供新增的早上好纯展示页面能力，页面通过一个后端 API 接口获取字符串“早上好”，并在页面主体展示“早上好!”，页面内容由接口返回值驱动（must）

## 页面清单

- `/page/home` 欢迎页：应用首页，采用侧边导航布局并展示页头（页脚禁用），页面主体居中展示写死的静态字符串“hello world”
- `/page/hello-agent` hello agent 页面：纯展示页面，可通过侧边导航进入，沿用侧边导航布局并展示页头（页脚禁用），页面主体展示写死的静态字符串“hello agent!”
- `/page/morning-greeting` 早上好页面：本轮新增的纯展示页面，可通过侧边导航进入，沿用侧边导航布局并展示页头（页脚禁用），页面加载时调用一个后端 API 接口获取字符串“早上好”，并在页面主体展示“早上好!”

## 实体清单

- 暂无实体

## 业务流程

- 浏览欢迎页：访客打开应用即可看到欢迎页内容，全流程为纯前端静态展示，不涉及登录、数据提交或后端交互；访客在 PC 浏览器中打开应用根路径 / → 应用加载欢迎页，渲染侧边导航布局与启用的页头，页脚不展示 → 页面主体内容区展示写死的静态字符串“hello world” → 访客浏览完成，无需登录或任何权限即可反复查看该页面
- 浏览 hello agent 页面：访客通过侧边导航进入 hello agent 纯展示页面即可看到“hello agent!”内容，全流程为纯前端静态展示，不涉及登录、数据提交或后端交互；访客在 PC 浏览器中打开应用，在侧边导航中点击 hello agent 页面入口 → 应用加载 hello agent 页面，沿用侧边导航布局与启用的页头，页脚不展示 → 页面主体内容区展示写死的静态字符串“hello agent!” → 访客浏览完成，无需登录或任何权限即可反复查看该页面
- 浏览早上好页面：访客通过侧边导航进入新增的早上好展示页面，页面调用后端 API 接口取回字符串“早上好”并展示为“早上好!”，无需登录与权限校验；访客在 PC 浏览器中打开应用，在侧边导航中点击早上好页面入口 → 应用加载早上好页面，沿用侧边导航布局与启用的页头，页脚不展示 → 页面调用后端 API 接口，请求返回字符串“早上好” → 页面主体内容区根据接口返回值展示字符串“早上好!” → 访客浏览完成，无需登录或任何权限即可反复查看该页面
