# 成都中心门禁卡管理系统需求 Spec

## 应用信息

- 名称：成都中心门禁卡管理系统
- 目标：移动端小程序（招乎APP扫码进入）为主，兼容PC前端展示
- 确认需求摘要：面向成都中心门禁卡管理的移动端（招乎APP扫码进入MP小程序）应用，同时在PC端保留问候展示能力。员工通过扫码识别本人身份，在移动端查看本人名下待领签的门禁卡申请明细并完成领用签收，查看本人名下使用中的门禁卡并发起离职注销申请；出差卡借用/归还仅作占位按钮。签收状态、注销申请等数据实时同步至飞码端门禁卡管理系统，审批与流程发起由飞码端完成，小程序不涉及管理权限。应用整体采用简洁扁平化的蓝色调风格。
- 状态：已确认
- 版本：1.2

## 业务参与者（非授权角色）

- `business_user` 全体员工：全体成都中心员工，通过招乎APP扫描二维码进入MP小程序，办理本人名下门禁卡的领用签收与离职注销申请，并查看本人名下的门禁卡数据。
- `general_affairs_admin` 综合事务室管理员：成都中心综合事务室负责场地运营方向的管理员，负责门禁卡管理的线下工作，包括回收员工线下交还的实体门禁卡。

## 权限需求

- 不涉及应用级资源授权。

## 认证需求

- 不涉及登录认证基础能力。

## 功能模块

- `greeting_display` 问候展示：调用后端接口获取问候字符串并展示在页面上。（must）
- `access_card_management` 门禁卡管理：提供门禁卡领用签收、离职注销申请以及出差卡借用/归还（占位）等移动端操作入口与功能。（must）

## 页面清单

- `/page/home` 欢迎页：首页展示后端接口返回的字符串「早上好！」，接口加载完成后在页面主体区域呈现该问候语。
- `/page/access_card/main` 门禁卡管理主页面：小程序首页与功能入口，用户扫码进入后首先展示。顶部居中显示标题「成都中心门禁卡管理系统」，中部纵向排列四个矩形功能按钮：门禁卡领用、门禁卡归还、出差卡借用、出差卡归还（后两个为占位按钮，展示禁用标识、暂不提供实际功能），底部边缘展示高楼大厦、柱状图等装饰图形。整体蓝色调、简洁扁平化。
- `/page/access_card/claim` 门禁卡领用页面：员工查看本人名下待领签的门禁卡申请明细并完成领用签收。页面自上而下为标题「门禁卡领用」、说明文案「所有字段信息直接从扫码获取，并实时同步到飞码」、可翻页的申请明细列表（字段：姓名、员工编号、卡号、领签状态）、操作区（【完成领签】按钮、【返回首页】按钮）及底部功能图标区；支持单条勾选与一键全选，仅展示本人名下【待领签】的明细。
- `/page/access_card/return` 门禁卡归还页面：员工查看本人名下状态为「使用中」的门禁卡并发起离职注销申请（页面标题为「门禁卡退还」）。页面自上而下为标题区、说明文案「所有字段信息直接从扫码获取，并实时同步到飞码」、可翻页的门禁卡信息列表（字段：姓名、员工编号、卡号、权限状态）、操作区（【离职注销】按钮、【返回首页】按钮）及底部功能图标区；点击【离职注销】提交注销申请后返回门禁卡管理主页面。
- `/page/access_card/cancel_completed` 已完成界面：离职注销申请提交成功后的确认提示页。居中展示标题「您已完成注销申请！」与说明文案「请把实体卡交给门禁卡管理员」，列出门禁卡管理员信息（园区：李媛/WS04462；OCG：徐敏/IT006877），并提供蓝色背景的【返回首页】按钮及底部功能图标区。

## 业务流程

- 查看欢迎问候：使用人员打开应用首页，前端调用接口获取问候字符串并展示。；使用人员打开应用首页 → 前端请求后端问候接口 → 接口返回字符串「早上好！」 → 前端在页面主体区域展示该字符串
- 门禁卡领用签收：员工通过招乎APP扫码进入小程序，查看本人名下待签收的门禁卡申请明细并完成领用签收，签收状态实时回传飞码。；员工使用招乎APP扫描二维码进入小程序 → MP识别扫码人ID → 通过扫码ID与领签人匹配，识别本人名下【待签收】的申请数据明细 → 手机端在门禁卡领用页面展示明细列表 → 员工单条勾选或一键全选待领签明细 → 点击【完成领签】，回填每条申请的【领签状态】为【已领签】 → 签收状态数据传回飞码
- 离职注销申请：员工查看本人名下使用中的门禁卡并发起离职注销申请，数据回传飞码触发注销流程，提交后返回门禁卡管理主页面，由员工线下将实体卡交还门禁卡管理员。；员工使用招乎APP扫描二维码进入小程序 → 识别扫码人ID，筛选本人名下【权限状态】为【使用中】的卡片信息展示 → 点击【离职注销】按钮 → 将【申请注销】字段更新为“离职” → 数据传回飞码，并在飞码发起现有注销流程 → 提交成功后返回门禁卡管理主页面
