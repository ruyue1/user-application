# 年龄录入需求 Spec

## 应用信息

- 名称：年龄录入
- 目标：
- 确认需求摘要：「年龄录入」是一个面向 PC 端的轻量应用，仅提供一个年龄录入页面：页面包含一个输入框用于填写年龄，提交后由后端仅保存年龄数值，不提供年龄数据的展示页面。本次迭代在后端新增一个获取年龄的接口，供后端按需读取已保存的年龄数值，前端不做任何改造。导航采用侧边布局，页头启用、页脚禁用，认证不启用，不涉及权限控制，业务角色为年龄录入人员。
- 状态：已确认
- 版本：1.0

## 业务参与者（非授权角色）

- `role_age_entry_user` 年龄录入人员：在年龄录入页面填写并提交年龄的业务人员

## 权限需求

- 不涉及应用级资源授权。

## 认证需求

- 不涉及登录认证基础能力。

## 功能模块

- `module_age_entry` 年龄录入：提供年龄录入页面，接收用户填写的年龄并提交保存，后端仅保存年龄数值（must）
- `module_age_query` 年龄获取：在后端新增获取年龄的接口，按需读取已保存的年龄数值，前端不涉及页面改造（must）

## 页面清单

- `/page/page/page-age-entry` 年龄录入：应用首页兼年龄录入页面，包含一个年龄输入框与提交操作，提交后仅保存年龄数值，不展示已录入数据；本次迭代前端保持不变

## 实体清单

- 暂无实体

## 业务流程

- 年龄录入流程：年龄录入人员通过唯一的录入页面填写年龄并提交，后端仅保存该年龄数值；打开年龄录入页面 → 在输入框中填写年龄 → 提交年龄 → 后端保存年龄数值并返回录入结果
- 年龄获取流程：后端提供获取年龄的接口，调用方通过该接口读取已保存的年龄数值，前端不参与该流程；调用方发起获取年龄的后端接口请求 → 后端读取已保存的年龄数值 → 后端返回年龄数值给调用方
