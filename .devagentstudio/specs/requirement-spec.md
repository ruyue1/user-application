# 成都中心门禁卡管理系统需求 Spec

## 应用信息

- 名称：成都中心门禁卡管理系统
- 目标：
- 确认需求摘要：面向成都中心全体员工的门禁卡管理移动端小程序，员工通过扫码身份识别后可在线完成本人名下门禁卡的领用签收与离职注销申请；出差卡借用与归还功能暂以占位按钮保留，不提供实际功能。所有数据与飞码端门禁卡管理系统实时同步，管理审批流程由飞码端负责。
- 状态：已确认
- 版本：1.0

## 业务参与者（非授权角色）

- `employee` 全体员工：成都中心所有持有门禁卡的员工，通过招乎APP扫码进入小程序，办理本人门禁卡领用签收与离职注销申请。
- `admin` 综合事务室管理员：成都中心综合事务室场地运营方向人员，负责门禁卡管理相关线下工作，如接收员工交还的实体卡。

## 权限需求

- 不涉及应用级资源授权。

## 认证需求

- 不涉及登录认证基础能力。

## 功能模块

- `module_access_card_management` 门禁卡管理：门禁卡领用签收、离职注销归还等核心业务功能，含出差卡占位入口。（must）

## 页面清单

- `/page/main` 主页面：小程序首页与功能入口，顶部居中展示标题「成都中心门禁卡管理系统」，主体纵向排列门禁卡领用、门禁卡归还、出差卡借用、出差卡归还四个矩形功能按钮，其中出差卡借用与归还为禁用占位按钮；页面底部为高楼大厦、柱状图等装饰图形。整体蓝色调、简洁扁平化。
- `/page/card/claim` 门禁卡领用页面：员工查看本人名下待领签的门禁卡申请明细并完成领用签收的页面。展示姓名、员工编号、卡号、领签状态等字段，支持单条勾选与一键全选、翻页浏览；点击完成领签后将领签状态更新为已领签并同步至飞码，可返回首页。
- `/page/card/return` 门禁卡归还页面：原型标题为门禁卡退还。员工查看本人名下权限状态为使用中的门禁卡信息（姓名、员工编号、卡号、权限状态），支持翻页；点击离职注销后更新申请注销字段并同步飞码，由飞码触发注销流程；可返回首页。
- `/page/card/deactivation-done` 已完成界面：离职注销申请提交成功后的确认提示页，标题为「您已完成注销申请！」，提示员工将实体卡交给门禁卡管理员，展示管理员信息（园区：李媛/WS04462；OCG：徐敏/IT006877），并提供蓝色背景的返回首页按钮。

## 业务流程

- 门禁卡领用签收流程：员工扫码进入小程序后完成本人名下待签收门禁卡申请明细的领用签收，并将签收状态回传飞码。；员工使用招乎APP扫描二维码进入MP小程序 → 小程序识别扫码人ID，并据此匹配本人名下的待签收申请数据明细 → 手机端展示本人名下待签收的门禁卡申请明细列表 → 员工单选或全选需要签收的申请明细 → 点击完成领签，系统将选中明细的签收状态回填为已签收 → 签收状态数据传回飞码端门禁卡管理系统
- 门禁卡离职注销流程：员工识别本人名下使用中的门禁卡并发起离职注销申请，由飞码端承接后续注销审批流程。；员工使用招乎APP扫描二维码进入小程序 → 小程序识别扫码人ID，筛选本人名下权限状态为使用中的卡片信息展示 → 员工点击离职注销按钮提交注销申请 → 系统将申请注销字段更新为离职并回传飞码，由飞码发起现有注销流程 → 员工点击返回首页回到主页面
