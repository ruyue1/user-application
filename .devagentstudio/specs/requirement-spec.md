# 人员明细需求 Spec

## 应用信息

- 名称：人员明细
- 目标：
- 确认需求摘要：「人员明细」是一款面向 PC 端的人员明细信息查看应用。应用以侧边导航布局呈现（页头启用、页脚禁用），既提供人员明细列表页（应用首页），任何使用者均可查看人员的基本明细信息，但不得新增、删除或修改人员信息，列表采用普通分页方式展示数据；也提供通过侧边导航进入的问候展示页，页面加载后自动调用后端接口，将接口返回的字符串「晚上好！」居中展示，并提供加载提示与异常提示。数据来源于数据库，应用不启用登录认证，也不涉及权限控制。
- 状态：已确认
- 版本：1.0

## 业务参与者（非授权角色）

- `personnel_viewer` 人员信息查看者：查看人员明细列表及人员基本明细信息的业务参与者，仅具备查看能力，不得删除、修改或查询检索以外的变更人员信息操作。

## 权限需求

- 不涉及应用级资源授权。

## 认证需求

- 不涉及登录认证基础能力。

## 功能模块

- `personnel_detail_management` 人员明细管理：承载人员明细信息的展示能力。维护人员明细列表的展示，包括人员基本明细信息的呈现。仅支持查看操作，不提供新增、删除、修改人员信息的能力。列表采用普通分页方式逐页浏览，不提供额外的检索、筛选或导出能力。该只读约束对本应用所有涉及人员明细的页面统一生效。（must）
- `greeting_display` 问候展示：承载问候信息的展示能力。页面加载后自动调用后端接口获取字符串「晚上好！」，并在页面中央居中展示该字符串；展示过程中提供加载提示与异常提示。仅支持查看展示，不提供任何数据新增、删除、修改或查询检索能力。该模块独立于人员明细管理模块，其页面同样沿用本应用整体「不启用认证、不涉及权限控制」的现状。（must）

## 页面清单

- `/page/pers-detail` 人员明细列表：人员明细列表页为本应用首页，位于启用页头的侧边导航布局中。页面以表格形式展示人员的明细信息，支持以普通分页方式逐页浏览人员数据。所有使用者均可查看人员明细列表，页面不提供人员信息的新增、删除、修改入口，也不提供除分页浏览外的其他数据处理操作。
- `/page/greeting` 问候展示：问候展示页通过侧边导航进入，不属于应用首页。页面加载后自动调用后端问候接口，获取接口返回的字符串「晚上好！」并以居中文本形式展示；请求过程中展示加载提示，请求失败时展示异常提示。页面不提供任何数据新增、删除、修改或检索操作。

## 业务流程

- 人员明细查看流程：使用者浏览人员明细信息的只读流程，贯穿列表页，遵循人员明细管理模块的只读约束。；使用者进入人员明细应用，通过侧边导航进入人员明细列表页 → 系统以表格形式展示人员的明细信息，并按普通分页方式分页呈现 → 使用者通过分页控件切换页面，逐页查看人员明细信息 → 使用者查看人员明细信息，系统不提供新增、删除或修改人员信息的操作入口
- 问候信息展示流程：使用者查看问候信息的只读流程，贯穿问候展示页，遵循问候展示模块的只读约束，不涉及任何数据变更操作。；使用者通过侧边导航进入问候展示页 → 页面加载后自动调用后端问候接口 → 系统在请求过程中展示加载提示 → 接口正常返回字符串「晚上好！」，页面以居中文本形式展示该字符串 → 若接口调用失败，页面展示异常提示，使用者可重新进入页面再次获取
