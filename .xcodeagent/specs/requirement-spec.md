# 欢迎页需求 Spec

## 应用信息

- 名称：欢迎页
- 目标：
- 确认需求摘要：「欢迎页」是一个面向内部员工的纯展示型 PC 应用，采用 side（侧边）导航布局，页头启用、页脚禁用。应用包含两个静态展示页面：原有的欢迎页直接展示写死的文案“hello world”，本次新增的 Agent 展示页直接展示写死的字符串“hello agent!”。两个页面均不依赖任何后端 API 接口，认证不启用，不涉及权限控制。
- 状态：已确认
- 版本：1.0

## 业务参与者（非授权角色）

- `internal_employee` 内部员工：组织内部成员，作为应用的访问者，打开欢迎页或新增的 Agent 展示页即可查看写死的展示文案。

## 权限需求

- 不涉及应用级资源授权。

## 认证需求

- 不涉及登录认证基础能力。

## 功能模块

- `welcome_display` 欢迎页展示：提供欢迎页的静态内容展示能力，直接呈现写死的字符串“hello world”，不包含任何后端接口调用。（must）
- `agent_greeting_display` Agent 展示页：新增的纯展示模块，直接呈现写死的字符串“hello agent!”，不包含任何后端接口调用。（must）

## 页面清单

- `/page/page/home` 欢迎页：应用首页，面向内部员工展示写死的欢迎文案“hello world”；使用 side 导航布局，页头启用、页脚禁用，无任何后端 API 交互。
- `/page/page/hello-agent` Agent 展示页：新增的纯展示页面，面向内部员工展示写死的字符串“hello agent!”；不涉及任何后端 API 交互，也不包含任何输入或操作控件。

## 实体清单

- 暂无实体

## 业务流程

- 查看欢迎页：内部员工打开应用后直接进入欢迎页，阅读写死的 hello world 欢迎文案。；内部员工在 PC 浏览器打开「欢迎页」应用 → 应用进入欢迎页首页，展示 side 导航布局与启用的页头 → 页面渲染写死的字符串“hello world”欢迎文案 → 内部员工阅读文案后离开或关闭页面
- 查看 Agent 展示页：内部员工通过导航进入新增的 Agent 展示页，查看写死的字符串“hello agent!”。；内部员工在 PC 浏览器打开「欢迎页」应用 → 内部员工通过 side 导航进入 Agent 展示页 → 页面直接渲染写死的字符串“hello agent!”，不发起任何后端接口请求 → 内部员工阅读文案后可返回欢迎页或关闭页面
