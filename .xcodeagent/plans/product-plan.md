# 欢迎页产品规划

- 摘要：「欢迎页」是一个面向 PC 终端的纯展示型应用，采用 side 侧边导航布局（页头启用、页脚禁用），不依赖任何后端 API 接口。应用包含两个纯展示页面：首页欢迎页展示写死的字符串“hello world”，本次迭代新增的 Hello Agent 展示页展示写死的字符串“hello agent!”。唯一参与者为访客（浏览者），无需认证与权限控制。
- 状态：confirmed
- 版本：0.1.0

## 页面与用户操作

### 欢迎页

- 页面 ID：`welcome_page`
- 路由：`/page/page/welcome`
- 页面目标：让访客打开应用后立即看到写死的“hello world”展示内容，无需任何输入或操作即可完成浏览。
- 页面跳转：无

业务信息：
- `welcome_page_greeting_text` 欢迎展示文本：页面主体区域展示的写死字符串“hello world”，是访客在本页唯一需要阅读的展示内容。
- `welcome_page_side_navigation` 侧边导航：应用统一的侧边导航区域，展示可进入的页面入口，帮助访客了解应用包含欢迎页与 Hello Agent 展示页。

核心操作：
- 无

产品验收标准：
- 访客在 PC 浏览器中打开应用首页时，页面主体区域展示写死的字符串“hello world”。
- 欢迎页采用 side 侧边导航布局，页头启用、页脚禁用。
- 欢迎页不包含任何输入框、按钮或需要访客操作才能看到展示内容的交互。
- 欢迎页不调用任何后端 API 接口即可完整展示内容。
- 访客无需登录即可直接浏览欢迎页内容。
### Hello Agent 展示页

- 页面 ID：`hello_agent_page`
- 路由：`/page/page/hello-agent`
- 页面目标：让访客通过侧边导航进入本页后，立即看到写死的“hello agent!”展示内容，无需任何输入或操作即可完成浏览。
- 页面跳转：无

业务信息：
- `hello_agent_page_greeting_text` Hello Agent 展示文本：页面主体区域展示的写死字符串“hello agent!”，是访客在本页唯一需要阅读的展示内容。
- `hello_agent_page_side_navigation` 侧边导航：应用统一的侧边导航区域，展示可进入的页面入口，访客可从中进入本页或返回欢迎页。

核心操作：
- 无

产品验收标准：
- 访客可通过侧边导航进入 Hello Agent 展示页。
- Hello Agent 展示页的主体区域展示写死的字符串“hello agent!”。
- Hello Agent 展示页采用 side 侧边导航布局，页头启用、页脚禁用。
- Hello Agent 展示页不包含任何输入框、按钮或需要访客操作才能看到展示内容的交互。
- Hello Agent 展示页不调用任何后端 API 接口即可完整展示内容。
- 访客无需登录即可直接浏览 Hello Agent 展示页内容。

## 产品级验收标准

- 应用包含欢迎页与 Hello Agent 展示页两个页面，均可被访客直接访问。
- 欢迎页主体区域展示写死的字符串“hello world”。
- Hello Agent 展示页主体区域展示写死的字符串“hello agent!”。
- 两个页面均采用 side 侧边导航布局，页头启用、页脚禁用。
- 两个页面均不依赖任何后端 API 接口即可完整展示内容。
- 访客无需登录、无需任何权限即可浏览全部页面内容。
- 两个页面均不包含输入、提交、导出等业务操作，仅提供只读展示内容。
