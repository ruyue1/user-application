# 欢迎页产品规划

- 摘要：「欢迎页」是一个面向 PC 终端的纯展示型应用，包含欢迎页与新增的 Hello Agent 展示页两个静态页面，分别直接展示写死的字符串“hello world”与“hello agent!”，均不依赖任何后端 API 接口。导航采用侧边布局，包含页头、不包含页脚。应用不启用认证，也不涉及权限控制，唯一的业务参与者是普通访问用户。
- 状态：confirmed
- 版本：0.1.0

## 页面与用户操作

### 欢迎页

- 页面 ID：`welcome_home`
- 路由：`/page/page/welcome-home`
- 页面目标：让普通访问用户在 PC 浏览器中打开应用后，立即看到写死的字符串 hello world，确认应用可正常访问并完成欢迎信息的查看。
- 页面跳转：无

业务信息：
- `welcome_home-greeting-text` 欢迎文案：页面直接展示的写死字符串 hello world，是普通访问用户在本页需要看到的唯一业务信息。

核心操作：
- 无

产品验收标准：
- 普通访问用户在 PC 浏览器中打开应用入口后，直接进入欢迎页。
- 欢迎页完整展示写死的字符串 hello world。
- 欢迎页不出现表单、列表或需要用户填写的输入项。
- 欢迎页在打开过程中不出现加载中、错误或空内容提示。
### Hello Agent 页

- 页面 ID：`hello_agent`
- 路由：`/page/page/hello-agent`
- 页面目标：让普通访问用户通过侧边导航进入 Hello Agent 页后，立即看到写死的字符串 hello agent!，完成新增展示内容的查看。
- 页面跳转：无

业务信息：
- `hello_agent-greeting-text` Hello Agent 文案：页面直接展示的写死字符串 hello agent!，是普通访问用户在本页需要看到的唯一业务信息。

核心操作：
- 无

产品验收标准：
- 普通访问用户可通过侧边导航进入 Hello Agent 页。
- Hello Agent 页完整展示写死的字符串 hello agent!。
- Hello Agent 页不出现表单、列表或需要用户填写的输入项。
- Hello Agent 页在打开过程中不出现加载中、错误或空内容提示。

## 产品级验收标准

- 应用包含欢迎页与 Hello Agent 页两个页面，均可通过侧边导航访问。
- 欢迎页展示写死的字符串 hello world，Hello Agent 页展示写死的字符串 hello agent!。
- 两个页面均为纯展示页面，不出现表单、列表或需要用户填写的输入项。
- 两个页面均不依赖任何后端接口，打开时不出现加载中、错误或空内容提示。
- 应用面向 PC 终端，导航采用侧边布局，包含页头、不包含页脚。
- 应用不启用认证，也不涉及权限控制，普通访问用户可直接查看两个页面的展示内容。
