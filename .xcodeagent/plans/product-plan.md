# agent欢迎页产品规划

- 摘要：面向 PC 端的纯展示型应用，在保留原有首页写死字符串 “hello world” 展示的基础上，新增一个纯展示页面，居中展示写死的字符串 “hello agent!”，两个页面均不包含任何后端 API 接口，不启用认证与权限控制。
- 状态：confirmed
- 版本：0.1.0

## 页面与用户操作

### 欢迎页

- 页面 ID：`home`
- 路由：`/page/page/home`
- 页面目标：让访问者在进入应用后立即看到写死的欢迎文案 “hello world”，确认应用已正常打开。
- 页面跳转：无

业务信息：
- `home_welcome_text` 欢迎文案：页面居中展示的写死字符串 “hello world”，用于向访问者传达应用已正常打开。

核心操作：
- 无

产品验收标准：
- 访问应用根路径时进入欢迎页。
- 欢迎页居中展示写死的字符串 “hello world”。
- 欢迎页不包含任何用户可触发的交互操作。
- 欢迎页不发起任何后端 API 请求。
- 欢迎页不要求用户登录或授权即可查看。
### agent 问候页

- 页面 ID：`hello_agent`
- 路由：`/page/page/hello-agent`
- 页面目标：让访问者在打开 agent 问候页后立即看到写死的问候文案 “hello agent!”，确认该展示页面已正常打开。
- 页面跳转：无

业务信息：
- `hello_agent_greeting_text` agent 问候文案：页面居中展示的写死字符串 “hello agent!”，用于向访问者传达 agent 问候展示内容。

核心操作：
- 无

产品验收标准：
- 访问 agent 问候页路径时进入该页面。
- agent 问候页居中展示写死的字符串 “hello agent!”。
- agent 问候页不包含任何用户可触发的交互操作。
- agent 问候页不发起任何后端 API 请求。
- agent 问候页不要求用户登录或授权即可查看。

## 产品级验收标准

- 应用包含欢迎页和 agent 问候页两个页面，均可通过各自路径访问。
- 欢迎页居中展示写死的字符串 “hello world”。
- agent 问候页居中展示写死的字符串 “hello agent!”。
- 两个页面均不包含任何用户可触发的交互操作。
- 两个页面均不发起任何后端 API 请求。
- 应用不启用认证与权限控制，所有访问者均可直接查看两个页面。
- 应用面向 PC 端展示，页面内容在 PC 端可正常阅读。
