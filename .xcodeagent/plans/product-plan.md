# 欢迎页产品规划

- 摘要：「欢迎页」是一个面向 PC 端的纯展示型应用，在原有欢迎页基础上新增一个纯展示页面，页面直接展示写死的字符串“hello agent!”，不依赖任何后端 API 接口与业务数据。应用采用 side 侧边导航布局，启用页头、禁用页脚，首页路径为 /，导航中包含欢迎页与 hello agent 展示页两个入口。面向的使用者为访客，无需登录即可浏览页面内容；应用不启用认证，也不做任何页面或操作级权限控制，任何访问者看到的展示内容完全一致。
- 状态：confirmed
- 版本：0.1.0

## 页面与用户操作

### 欢迎页

- 页面 ID：`home`
- 路由：`/page/home`
- 页面目标：让访客打开应用后立即看到写死的欢迎字符串“hello world”，无需登录、无需任何操作即可完成浏览。
- 页面跳转：hello_agent_page

业务信息：
- `home_welcome_text` 欢迎展示文案：页面中央固定展示的字符串“hello world”，是访客进入应用后看到的核心内容。
- `home_nav_entry` 侧边导航入口：side 侧边导航中提供的页面入口，帮助访客了解当前应用包含欢迎页与 hello agent 展示页两个可浏览页面。

核心操作：
- 无

产品验收标准：
- 访客打开应用首页时，页面中央展示写死的字符串“hello world”。
- 首页不出现任何表单、按钮或数据请求相关的交互内容。
- 访客无需登录即可直接浏览首页展示内容。
- side 侧边导航中同时可见欢迎页与 hello agent 展示页两个入口。
### hello agent 展示页

- 页面 ID：`hello_agent_page`
- 路由：`/page/hello-agent`
- 页面目标：让访客通过侧边导航进入该页面后，立即看到写死的字符串“hello agent!”，无需登录、无需任何操作即可完成浏览。
- 页面跳转：home

业务信息：
- `hello_agent_page_display_text` hello agent 展示文案：页面中央固定展示的字符串“hello agent!”，是访客进入该页面后看到的核心内容。
- `hello_agent_page_nav_entry` 侧边导航入口：side 侧边导航中提供的页面入口，帮助访客在欢迎页与该展示页之间切换浏览。

核心操作：
- 无

产品验收标准：
- 访客通过 side 侧边导航点击「hello agent 展示页」入口后，页面中央展示写死的字符串“hello agent!”。
- 该页面不出现任何表单、按钮或数据请求相关的交互内容。
- 访客无需登录即可直接浏览该页面展示内容。
- 该页面与欢迎页在侧边导航中均可被访客识别并切换。

## 产品级验收标准

- 应用包含欢迎页与 hello agent 展示页两个页面，均可由访客无需登录直接访问。
- 欢迎页展示写死的字符串“hello world”，hello agent 展示页展示写死的字符串“hello agent!”。
- 两个页面均为纯静态展示，不出现表单、按钮或任何数据请求相关的交互内容。
- 应用采用 side 侧边导航布局，导航中同时包含欢迎页与 hello agent 展示页两个入口。
- 应用启用页头、禁用页脚，首页路径为 /。
- 任何访客看到的展示内容完全一致，不因身份或权限不同而变化。
