# 欢迎页产品规划

- 摘要：一个面向 PC 终端的纯展示应用，首页仅展示写死的字符串「hello world」，不包含任何后端 API 接口，认证不启用，也不涉及权限控制。
- 状态：confirmed
- 版本：0.1.0

## 页面与用户操作

### 欢迎页

- 页面 ID：`home`
- 路由：`/page/home`
- 页面目标：让访客在 PC 终端打开应用后，能够立即看到写死的「hello world」欢迎内容，完成一次纯展示的浏览体验。
- 页面跳转：无

业务信息：
- `home-welcome-text` 欢迎文案：页面中央展示的写死字符串「hello world」，用于向访客传达欢迎信息。

核心操作：
- 无

产品验收标准：
- 访客在 PC 浏览器中打开应用入口后，能够看到欢迎页。
- 欢迎页上完整展示写死的字符串「hello world」。
- 欢迎页不请求任何后端接口，也不展示任何数据列表或表单。
- 欢迎页采用侧边导航布局，页头启用，页脚禁用。
