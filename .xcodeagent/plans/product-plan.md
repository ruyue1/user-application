# 欢迎页产品规划

- 摘要：一个面向 PC 终端的纯展示应用，在既有首页展示写死字符串「hello world」的基础上，本次迭代新增一个纯展示页面用于展示写死字符串「hello agent!」，两个页面均为静态渲染、不请求任何后端 API 接口，认证与权限控制均不启用。
- 状态：confirmed
- 版本：0.1.0

## 页面与用户操作

### 欢迎页

- 页面 ID：`home`
- 路由：`/page/home`
- 页面目标：让访客在 PC 终端打开应用后，能够立即看到写死的「hello world」欢迎内容，完成一次纯展示的浏览体验。
- 页面跳转：无

业务信息：
- `home_welcome_text` 欢迎文案：页面中央展示的写死字符串「hello world」，作为访客打开应用后看到的核心欢迎内容。
- `home_page_title` 页面标题：标识当前页面为欢迎页的标题信息，帮助访客确认所处页面。

核心操作：
- 无

产品验收标准：
- 访客在 PC 浏览器中打开应用入口后，默认落地到欢迎页。
- 欢迎页上清晰展示写死的字符串「hello world」。
- 欢迎页不发起任何后端接口请求，页面内容不依赖外部数据。
- 访客无需登录即可查看欢迎页内容。
### Agent 欢迎页

- 页面 ID：`agent_welcome`
- 路由：`/page/agent-welcome`
- 页面目标：让访客能够进入本次迭代新增的 Agent 欢迎页，查看写死的「hello agent!」展示内容，完成一次纯展示的浏览体验。
- 页面跳转：无

业务信息：
- `agent_welcome_text` Agent 欢迎文案：页面中央展示的写死字符串「hello agent!」，作为本次迭代新增页面的核心展示内容。
- `agent_welcome_page_title` 页面标题：标识当前页面为 Agent 欢迎页的标题信息，帮助访客确认所处页面。

核心操作：
- 无

产品验收标准：
- 访客可通过应用侧边导航进入 Agent 欢迎页。
- Agent 欢迎页上清晰展示写死的字符串「hello agent!」。
- Agent 欢迎页不发起任何后端接口请求，页面内容不依赖外部数据。
- 访客无需登录即可查看 Agent 欢迎页内容。

## 产品级验收标准

- 应用包含欢迎页与 Agent 欢迎页两个页面，均可通过侧边导航访问。
- 欢迎页展示写死的字符串「hello world」，Agent 欢迎页展示写死的字符串「hello agent!」。
- 两个页面均为纯静态展示，不请求任何后端 API 接口。
- 应用不启用认证与权限控制，访客无需登录即可浏览全部页面内容。
- 应用面向 PC 终端，采用侧边导航布局，启用页头，禁用页脚。
