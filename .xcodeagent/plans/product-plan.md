# 欢迎页产品规划

- 摘要：「欢迎页」是一个面向内部员工的纯展示型 PC 应用，采用 side（侧边）导航布局，页头启用、页脚禁用。应用包含两个静态展示页面：原有的欢迎页直接展示写死的文案“hello world”，本次新增的 Agent 展示页直接展示写死的字符串“hello agent!”。两个页面均不依赖任何后端 API 接口，认证不启用，不涉及权限控制。
- 状态：confirmed
- 版本：0.1.0

## 页面与用户操作

### 欢迎页

- 页面 ID：`home`
- 路由：`/page/page/home`
- 页面目标：让内部员工打开应用后立即看到写死的欢迎文案“hello world”，无需任何操作即可完成信息获取。
- 页面跳转：agent_greeting

业务信息：
- `home_welcome_text` 欢迎文案：页面直接展示的写死字符串“hello world”，作为内部员工进入应用后看到的主要信息。
- `home_navigation_menu` 侧边导航菜单：side 布局下展示的导航菜单，包含欢迎页与 Agent 展示页入口，供内部员工在页面之间切换。

核心操作：
- `home_navigate_to_agent_greeting` 进入 Agent 展示页：内部员工通过侧边导航菜单点击 Agent 展示页入口，切换到 Agent 展示页。；页面跳转；预期结果 页面切换到 Agent 展示页，展示写死的字符串“hello agent!”。；目标页面 `agent_greeting`

产品验收标准：
- 内部员工打开应用后默认进入欢迎页，页面展示写死的字符串“hello world”。
- 欢迎页使用 side 导航布局，页头启用、页脚禁用。
- 欢迎页不发起任何后端接口请求，也不展示加载中或错误提示。
- 内部员工可通过侧边导航菜单进入 Agent 展示页。
### Agent 展示页

- 页面 ID：`agent_greeting`
- 路由：`/page/page/hello-agent`
- 页面目标：让内部员工通过侧边导航进入该页面后，直接看到写死的字符串“hello agent!”，无需任何操作即可完成信息获取。
- 页面跳转：home

业务信息：
- `agent_greeting_text` Agent 展示文案：页面直接展示的写死字符串“hello agent!”，作为内部员工进入该页面后看到的主要信息。
- `agent_greeting_navigation_menu` 侧边导航菜单：side 布局下展示的导航菜单，包含欢迎页与 Agent 展示页入口，供内部员工在页面之间切换。

核心操作：
- `agent_greeting_navigate_to_home` 返回欢迎页：内部员工通过侧边导航菜单点击欢迎页入口，切换回欢迎页。；页面跳转；预期结果 页面切换回欢迎页，展示写死的字符串“hello world”。；目标页面 `home`

产品验收标准：
- 内部员工通过侧边导航进入 Agent 展示页后，页面展示写死的字符串“hello agent!”。
- Agent 展示页使用 side 导航布局，页头启用、页脚禁用。
- Agent 展示页不发起任何后端接口请求，也不展示加载中或错误提示。
- Agent 展示页不包含任何输入或操作控件，仅提供静态展示内容。
- 内部员工可通过侧边导航菜单返回欢迎页。

## 产品级验收标准

- 应用包含欢迎页与 Agent 展示页两个页面，均可通过 side 导航布局访问。
- 欢迎页展示写死的字符串“hello world”，Agent 展示页展示写死的字符串“hello agent!”。
- 两个页面均不依赖任何后端 API 接口，打开后直接呈现静态文案。
- 应用采用 side 导航布局，页头启用、页脚禁用。
- 应用不启用认证，不涉及权限控制，内部员工可直接访问两个页面。
- 两个页面均不包含任何输入控件，不涉及校验状态。
