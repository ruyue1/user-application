### 需求规格

> 「欢迎页」是一个面向 PC 终端的纯展示型应用，只包含一个欢迎页，页面直接展示写死的字符串“hello world”，不依赖任何后端 API 接口。导航采用侧边布局，包含页头、不包含页脚。应用不启用认证，也不涉及权限控制，唯一的业务参与者是普通访问用户。

**用户角色**：
- 普通访问用户：打开应用并查看欢迎页上展示的 hello world 文案的访问者，不承担任何管理或其他业务职责

**功能模块**：
- 欢迎页展示（must）：提供 PC 端欢迎页的静态内容展示能力，页面渲染写死的字符串 hello world，不调用任何后端接口

### 产品计划

**页面**：
- **欢迎页**（welcome_home，路径：/page/welcome-home）
  - 描述：应用首页与唯一页面，在 PC 浏览器中直接展示写死的字符串 hello world，无表单、无列表、无交互请求
  - 目标：让普通访问用户在 PC 浏览器中打开应用后，立即看到写死的字符串 hello world，确认应用可正常访问并完成欢迎信息的查看。

**业务流程**：
- 查看欢迎页
  - 普通访问用户在 PC 浏览器中打开应用并查看欢迎页展示的 hello world 文案的完整流程
  - 步骤：普通访问用户在 PC 浏览器中打开应用入口
  - 步骤：系统直接渲染欢迎页
  - 步骤：欢迎页展示写死的字符串 hello world
  - 步骤：普通访问用户查看页面展示内容，流程结束

### 技术计划

- 前端架构：A PC-oriented single-page welcome client renders a static hello world message without any backend API dependency.
- 后端架构：后端技术栈固定为 Java8 + Springboot，提供真实 HTTP API、资源接口和业务契约实现。
- 数据层：数据库固定使用 MySQL8，缓存固定使用 Redis。
