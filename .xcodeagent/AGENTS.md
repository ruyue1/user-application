# 迭代上下文

## v1.0（2026-09-17 08:34:38 UTC）

**版本说明**：初始版本：调查问卷应用

### 应用现状

- 应用名称：调查问卷
- 应用场景：帮我开发一个用于收集大学生职业发展规划的调查问卷，只需要一个表单
- 目标终端：PC
- 导航布局：布局=side, 页头=启用, 页脚=禁用
- 主题色：#6b3cf0
- 数据源类型：database
- 认证：不启用
- 权限控制：不启用
- 已有页面：工作台

### 需求规格

> 用于收集大学生职业发展规划的调查问卷应用，提供一个表单供学生填写并提交。

**用户角色**：
- 学生：填写职业发展规划调查问卷的大学生

**功能模块**：
- 问卷调查（must）：大学生职业发展规划调查问卷的填写与提交

### 产品计划

**页面**：
- **首页**（home，路径：/page/home）
  - 描述：调查问卷应用首页，展示问卷填写入口
  - 目标：向学生介绍调查问卷的目的与填写要求，并提供进入问卷填写页面的入口
  - 信息项：问卷介绍
- **问卷填写**（survey_form，路径：/page/survey_form）
  - 描述：调查问卷填写页面，提供多分区问卷表单
  - 目标：让学生填写职业发展规划相关信息并提交
  - 信息项：姓名, 学号, 专业, 年级, 职业目标, 自我能力评估, 发展规划

**业务流程**：
- 填写调查问卷
  - 学生进入问卷填写页面，填写职业发展规划相关信息并提交
  - 步骤：学生进入问卷填写页面
  - 步骤：学生填写职业发展规划相关信息
  - 步骤：学生提交问卷

### UI 设计稿

- home：首页采用侧边导航+顶部页头布局，主区域展示问卷介绍文案和进入填写按钮
- survey_form：问卷填写页采用分区表单布局，包含个人信息区、职业规划区，底部有提交按钮

### 技术计划

- 前端架构：React 单页应用，PC 侧边导航布局，页头启用页脚禁用。首页展示问卷介绍内容，问卷填写页提供多分区表单和客户端必填校验，提交失败时保留已填内容。
- 后端架构：Java8 + Springboot，提供真实 HTTP API、资源接口和业务契约实现。
- 数据层：数据库固定使用 MySQL8，缓存固定使用 Redis。

**实体**：
- **调查问卷提交**（SurveySubmission）
  - 描述：学生提交的职业发展规划调查问卷记录，包含个人基本信息、职业目标、自我能力评估与发展规划等内容。
  - 姓名（student_name）：text，必填
  - 学号（student_id）：text，必填
  - 专业（major）：text，必填
  - 年级（grade）：enum，必填
  - 职业目标（career_goal）：textarea，必填
  - 自我能力评估（self_assessment）：textarea，选填
  - 发展规划（development_plan）：textarea，选填

### 接口设计

- **获取问卷信息**
  - GET /api/survey/info
  - 描述：获取调查问卷的基本信息，用于首页展示
- **提交问卷**
  - POST /api/survey/submit
  - 描述：学生提交填写好的调查问卷

### 数据源

- **提交表单**（类型：external_api）
  - 地址：http://127.0.0.1
