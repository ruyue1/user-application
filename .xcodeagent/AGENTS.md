### 需求规格

> 「欢迎页」是一个面向 PC 端的纯展示型应用，仅提供单个欢迎页，页面直接展示写死的字符串“hello world”，不依赖任何后端 API 接口与业务数据。应用采用 side 侧边导航布局，启用页头、禁用页脚，首页路径为 /，导航中仅包含该欢迎页。面向的使用者为访客，无需登录即可浏览页面内容；应用不启用认证，也不做任何页面或操作级权限控制，任何访问者看到的展示内容完全一致。

**用户角色**：
- 访客：无需登录、可直接打开欢迎页浏览 hello world 展示内容的访问者，是本应用唯一的使用角色。

**功能模块**：
- 欢迎页展示（must）：应用的核心展示模块，负责在首页向访问者展示写死的欢迎字符串“hello world”，不含任何后端接口调用与数据交互。

### 产品计划

**页面**：
- **欢迎页**（home，路径：/page/home）
  - 描述：应用首页，页面中央展示写死的字符串“hello world”，纯静态展示内容，不含表单、按钮或任何数据请求。
  - 目标：让访客打开应用后立即看到写死的欢迎字符串“hello world”，无需登录、无需任何操作即可完成浏览。

**业务流程**：
- 查看欢迎页
  - 访客打开应用后直接进入欢迎页并阅读 hello world 展示内容的最简浏览流程，全程无需登录或选择操作。
  - 步骤：访客在浏览器中打开应用地址
  - 步骤：系统直接渲染首页欢迎页
  - 步骤：页面展示写死的字符串“hello world”
  - 步骤：访客阅读展示内容后结束浏览

### 技术计划

- 前端架构：A PC-oriented single-page welcome client renders a static page with a side navigation layout, header enabled, footer disabled, and the home route at /.
- 后端架构：后端技术栈固定为 Java8 + Springboot，提供真实 HTTP API、资源接口和业务契约实现。
- 数据层：数据库固定使用 MySQL8，缓存固定使用 Redis。
